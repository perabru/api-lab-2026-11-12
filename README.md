**Desenvolvimento agendado para 12/11/2026, com início às 07h, no horário de Brasília.**

## A proposta

Livros, autores e busca; operações locais de empréstimo sem depender de extração em massa da Open Library.

A referência de estudo é a **Open Library APIs**. O projeto terá implementação própria, sem vínculo ou afiliação com o provedor usado como inspiração.

[Consultar a documentação de referência](https://openlibrary.org/developers/api) · [Ver o plano dos 10 dias](https://github.com/perabru/peradev-apis/blob/main/docs/10-days.md)

## O que será entregue

- [ ] API pequena, funcional e com escopo claro.
- [ ] Validação, erros explicados e persistência quando necessária.
- [ ] Exemplos executáveis e contrato das rotas.
- [ ] Testes de comportamento com resultados reais.
- [ ] Instruções de execução, limites e referências oficiais.
- [ ] Texto para LinkedIn em `LINKEDIN.md`, preparado para revisão.

O código será publicado neste repositório. A preparação do texto para LinkedIn não equivale a publicação automática na rede social.
